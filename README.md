# mon-premier-projet

Mon premier projet GitHub 🚀

## Description

Ce projet est une introduction à l'utilisation de GitHub. Il me permet de me familiariser avec les concepts de base : dépôts, commits, branches et collaboration.

## Fonctionnalités

- Initialisation d'un dépôt Git
- Gestion des fichiers avec commits
- Utilisation des branches
- Collaboration via GitHub

## Installation

```bash
git clone https://github.com/davidldo/mon-premier-projet.git
cd mon-premier-projet
```

## Utilisation

```bash
# Exemple de commande
git status
git add .
git commit -m "Mon premier commit"
```

## Technologies utilisées

- Git
- GitHub
- Markdown
